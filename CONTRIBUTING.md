# Contributing to Open Prompting Guide

Thank you for contributing.

Open Prompting Guide is a simple, open-source effort to make prompt engineering techniques clearer, more practical, and easier to apply.

We welcome improvements of all kinds — especially those that improve clarity.

---

## What you can contribute

You can help by:

- Improving explanations (clarity, simplicity, structure)
- Fixing mistakes or unclear parts
- Adding practical examples
- Suggesting better ways to explain a technique
- Expanding existing sections (Chain-of-Thought, ReAct, agents, etc.)
- Reporting issues or confusing sections
- Improving diagrams or visual explanations

---

## How to start

1. Fork the repository
2. Create a new branch
3. Make small and focused changes
4. Keep explanations clear and simple
5. Submit a pull request

---

## Writing style

To keep the guide consistent:

- Prefer simple and direct language
- Explain ideas step by step
- Avoid unnecessary jargon
- Focus on understanding and practical application
- Use concrete examples whenever possible

---

## Pull Requests

When submitting a PR:

- Keep changes small and focused
- Explain what you improved and why
- Link to the related issue (if any)

We review contributions as quickly as possible.

---

## Issues

If something is unclear, outdated, or missing:

Open an issue and describe:

- what is confusing
- where it happens
- what you suggest instead (if possible)

---

## Code of Conduct

Be respectful and constructive.

This is a learning-focused project, and all contributions should help improve understanding.

---

Thank you for helping improve Open Prompting Guide.
