# Open Prompt Engineering Guide

**Building a future where no one is left behind by the AI revolution.**

[![Community Driven](https://img.shields.io/badge/Community-Driven-blue)](https://github.com/yourusername/prompting-guide) [![Open Source](https://img.shields.io/badge/Open-Source-green)](LICENSE) [![License: CC BY-SA](https://img.shields.io/badge/License-CC%20BY--SA-lightgrey)](https://creativecommons.org/licenses/by-sa/4.0/)

We believe that the ability to communicate effectively with AI is becoming as fundamental as reading and writing. In a world where AI is transforming work, creativity, and problem-solving, too many feel left behind or overwhelmed, and we believe everyone deserves the confidence and capability to harness these tools for their own growth and creativity.
We envision a future where everyone can speak AI fluently, turning technological advancement into universal human advancement.

We achieve this by building the world's clearest, most accessible resource for prompt engineering. Specifically, we provide a free, open-source, community-driven guide that is trustworthy and organized, featuring:

- **Clear, beginner-friendly learning paths** that transform confusion into competence
- **Hands-on exercises and templates** that deliver immediate results
- **Model-agnostic, framework-focused principles** that teach underlying thinking, not just commands
- **Step-by-step progressive learning** where each lesson builds on the last
- **Free, open-access education** that breaks down financial and technical barriers

## Running the Guide Locally

This guide is built with [Docusaurus](https://docusaurus.io/), a modern static website generator. To run it locally for development or exploration:

```bash
# 1. Clone and navigate
git clone https://github.com/yourusername/prompting-guide.git
cd prompting-guide

# 2. Install dependencies
npm install  # or yarn install

# 3. Start the development server
npm start    # or yarn start
```
Once running, open http://localhost:3000 in your browser. The site will automatically reload as you make changes.
