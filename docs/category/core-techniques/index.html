Core Techniques

Essential prompting methods that form the foundation of effective interaction with large language models — from zero-shot and few-shot to Chain-of-Thought, ReAct, and beyond.

📄️ Zero-Shot & Few-Shot Prompting

You've learned how to write clear, structured prompts — but sometimes, even clear instructions lead to confusing results.

📄️ Chain-of-Thought Prompting

You've seen how examples can shape what a model says.

📄️ Meta Prompting

You’ve learned how to write clear instructions, teach with examples, and guide step-by-step reasoning.

📄️ Self-Consistency

Chain-of-Thought (CoT) prompting encourages language models to show their work step-by-step. But what happens if the model makes a minor arithmetic or logical misstep early on, the entire final answer falls apart.

📄️ Generated Knowledge Prompting

You’ve learned how to guide reasoning step-by-step and sample multiple pathways for accuracy. But what happens when a model fails simply because it makes a wrong factual assumption?

📄️ Prompt Chaining

You’ve learned several ways to improve a single prompt: clearer instructions, examples, step-by-step reasoning, multiple attempts, and generated knowledge.

📄️ Tree of Thoughts (ToT)

You’ve seen how Chain-of-Thought guides a model step by step, and how Self-Consistency samples multiple paths and votes on the answer.

📄️ Retrieval-Augmented Generation (RAG)

Language models are powerful, but their knowledge is limited to what they learned during training. When a question requires up-to-date, specialized, or highly specific information, the model can guess — and sometimes invent facts.

📄️ Automatic Reasoning and Tool-use (ART)

You’ve learned how to break tasks into linear pipelines, explore branching thoughts, and ground models using external knowledge through RAG.

📄️ Automatic Prompt Engineer (APE)

You’ve learned how to design prompts manually — from writing clear instructions and few-shot examples to structuring multi-step reasoning, RAG pipelines, and tool execution.

📄️ Active-Prompt

You’ve learned how techniques like Few-Shot CoT rely on human-annotated step-by-step examples to guide language models through complex reasoning tasks.

📄️ Directional Stimulus Prompting (DSP)

You’ve learned how to optimize prompts automatically using frameworks like APE, select high-value annotations with Active-Prompt, and ground model responses using external tools or RAG.

📄️ Program-Aided Language Models (PAL)

You’ve learned how to guide models using step-by-step reasoning, external tools, and automated pipelines.

📄️ ReAct Prompting

You’ve learned how to guide models through step-by-step text reasoning, ground them with external facts using RAG, and even let them write code execution scripts using PAL.

📄️ Reflexion

You've learned how ReAct allows a language model to interleave reasoning and actions. However, when the model makes a mistake, it usually starts the next attempt from scratch.

📄️ Multimodal Chain-of-Thought Prompting

You’ve learned how to guide models using text-based Chain-of-Thought (CoT) reasoning, ReAct loops, and verbal reflection.
